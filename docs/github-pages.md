# Тестовая публикация GitHub Pages

В репозитории уже включён GitHub Pages. Для совместимости с публикацией `main / (root)` в корне хранится **генерируемый статический снимок** нового сайта. Список его файлов — `.pages-manifest.json`. Исходники остаются в `src/` и `public/`.

Тестовый адрес: https://nst0v.github.io/SoldatovWeb/

После изменения исходников выполните `npm run check`, затем `npm run pages` и закоммитьте обновлённые файлы снимка. Не редактируйте корневые HTML/CSS/JS вручную: они будут перезаписаны следующей сборкой. В частности, добавление исходника без обновления снимка не меняет опубликованную страницу.

`npm run pages` всегда создаёт noindex-предпросмотр с явной подготовкой почтового черновика. Команда не переносит PHP-обработчик, секреты и настройки автоматической отправки в корень. Исходные тексты и изображения публичны, как и сам репозиторий. Не добавляйте сюда конфиденциальные данные.

Для обычного хостинга используйте `npm run build` и содержимое `dist/` по инструкции README. Настройка `SITE_ORIGIN` и реальная серверная форма относятся к этому режиму, а не к тестовой публикации Pages. DNS и основной домен этой процедурой не меняются.
