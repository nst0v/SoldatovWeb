# Бренд и структура

SAYT■MSK. Оранжевый квадрат в логотипе, светлый фон, графитовый текст. Синие и оранжевые акценты, скруглённые кубики из утверждённого лукбука. Никаких персонажей, лиц и игрушечной анимации.

Цвет/значение не меняются между разделами: стратегия — оранжевый/лампочка; дизайн — светлый/кисть; разработка — синий/код; SEO — светлый/лупа; реклама — оранжевый/мегафон; аналитика — синий/диаграмма; интеграции — светлый/цепь; поддержка — оранжевый/шестерёнка; контент — синий/изображение; запуск — светлый/ракета.

Главная продаёт понятные форматы: лендинг, сайт компании, магазин, доработка. Технические модули поясняют состав, а не заставляют клиента самому собирать смету. Нет обязательной покупки десяти направлений.

Ритм: hero → четыре карточки → большие примеры → преимущества → строки дополнительных услуг → зачем нужен сайт → стоимость с раскрытиями → этапы → FAQ → обращение → подвал. Подробности направлений вынесены на отдельные страницы. Все подписи и тексты — HTML, не в картинках. Важное содержимое доступно без JS. Системные шрифты, без внешних файлов и font CDN.
