# SAYTMSK

Новая версия сайта вместо Soldatov.dev. Светлая айдентика, оранжевые/синие/светлые кубики без персонажей. Главная и девять отдельных страниц услуг. Старая версия сохранена в истории Git и ветке `archive/soldatov-dev-before-saytmsk`.

## Запуск

Node.js 22+, без сторонних npm-зависимостей:

```sh
npm run dev
# http://127.0.0.1:8080
npm run build
# Готовый сайт — dist/
```

На обычный хостинг загружается **содержимое `dist/`**, а не исходный репозиторий. Для GitHub Pages подходят статические файлы, PHP там не выполняется. Папка `dist/` не хранится в Git: она воспроизводимо собирается из исходников. В Actions → Verify SAYTMSK → `saytmsk-preview` есть ZIP сайта и проверки.

## Что внутри

- Главная: шапка с раскрывающейся навигацией, четыре основных предложения, примеры работ, преимущества, дополнительные услуги, зачем нужен сайт, стоимость, этапы, FAQ и контакты.
- Страницы: лендинг, сайт компании, интернет-магазин, доработка, SEO, реклама, аналитика, интеграции и поддержка.
- `src/content.mjs` — единый источник текстов, услуг, контактов и примеров.
- `src/render.mjs` — HTML-компоненты и страницы; основной контент работает без JavaScript.
- `public/styles.css` — токены, сетки и адаптивность.
- `public/app.js` — меню и обращение; нет трекеров и внешнего runtime.
- `public/assets/cubes.webp` — прозрачный оптимизированный атлас из утверждённого лукбука, не случайные новые иконки.
- `public/api/contact.php` — опциональная отправка через PHP, выключена по умолчанию.
- `tests/` — проверки HTML, маршрутов, браузера и защит обработчика.

## Как работает обращение сейчас

Сохранены Telegram, email и телефон из старого репозитория. Их актуальность нужно подтвердить перед рекламным запуском.

По умолчанию форма **готовит письмо локально**, а не делает вид, что заявка отправлена. Кнопка «Подготовить письмо» показывает текст, ссылку для открытия почты и копирование. Пользователь сам отправляет письмо. Ничего не сохраняется на сервере. Можно сразу перейти в Telegram, позвонить или написать на почту.

Автоматическая отправка — отдельный режим. Перед её включением необходимо подготовить реальные условия обработки данных и серверное окружение. В shell сборки задаются `FORM_ENDPOINT=/api/contact.php` и `PRIVACY_URL=/реальная-страница-условий/`. На PHP-хостинге задаются `FORM_ENABLED=1`, `FORM_PRIVACY_READY=1`, `FORM_ORIGIN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Пример переменных — `.env.example`; он НЕ загружается автоматически. Реальные значения задавайте через настройки хостинга, не коммитьте `.env`.

Обработчик проверяет метод, размер, Origin, поля, согласие, honeypot и лимит повторов. Сообщение отправляется без HTML-разметки. Успех возвращается только при подтверждении Telegram. В тестах реальные сообщения не отправляются. Сохранность и политика обработки данных требуют проверки владельца; наличие кода не означает юридическую готовность сайта.

## Индексация и домен

Без `SITE_ORIGIN` сборка считается предпросмотром: `noindex` и закрывающий `robots.txt`. Для согласованного основного домена:

```sh
SITE_ORIGIN=https://saytmsk.ru npm run build
```

Это пример настройки, а не подтверждение покупки домена. В production-сборке появятся canonical и sitemap. При размещении в подкаталоге задайте `PUBLIC_BASE_PATH=/SoldatovWeb/` (нужно в том числе для страницы 404). Все обычные маршруты и ассеты используют относительные адреса.

## Примеры работ

АМУР обозначен как демонстрационный проект, «Без вмятин» — как концепция редизайна. Клиентские результаты и оплаченный запуск не заявляются. В CI `scripts/capture-work.py` пытается сделать **реальные** снимки двух публичных демосайтов. Если адрес недоступен, остаётся типографическая карточка со ссылкой, а не вымышленный скриншот. Происхождение данных — `docs/content-sources.md`.

## Проверки

```sh
npm run check
php -l public/api/contact.php
python tests/backend.py
# После установки playwright и Chromium:
python tests/browser.py                 # без сетевых запросов, DOM в памяти
BROWSER_HTTP=1 python tests/browser.py  # страницы через локальный HTTP
python scripts/package.py
```

Зависимости только для тестов: `playwright==1.57.0`, `Pillow==11.3.0`. Для установки браузера: `python -m playwright install chromium`.

Локально проверяются ширины 320–1920 px, клавиатура, меню, FAQ, формы и девять страниц услуг. Успех/ошибка автоматической отправки проверяются подменой транспорта, а не отправкой в реальный аккаунт. Отчёт и скриншоты — `artifacts/`. Отчёт конкретного запуска является подтверждением проверок, README — нет.
